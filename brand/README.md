# Lenviq brand assets

Everything here is generated by `node scripts/build-brand.mjs` from the chosen mark and the
self-hosted fonts, then copied into each application's `public/` by `scripts/sync-brand.mjs`.
Nothing in this folder should be edited by hand — edit the script.

## The mark

### Three directions were drawn

Each was rendered at 16px true size, magnified 8×, and checked in one colour and reversed out of
slate before choosing. The renders are the reason for the choice, not a description of them.

**A — Ledger.** A spine and a base rule form an L; two entry lines sit against it. Reads as a
ruled ledger page and as the letter L at the same time. The product is a book of record — immutable
postings, an append-only audit log — so the mark is the thing itself rather than a metaphor for it.

**B — Interlock.** Two crossing planes, the overlap in a darker tone. The boldest at 16px and the
weakest at 200px: at size it reads as a generic two-tone L, and the darker overlap square is
arbitrary once you look at it. Closest of the three to startup-generic.

**C — Seal.** A notched octagon holding an L, referencing an attestation seal — apt for a product
whose strongest claim is regulatory and whose author is a practising CA and CS. **Failed the 16px
test outright:** the octagon's mass swallows the counter and the L becomes a smudge. It also reads
as governmental rather than as software.

### A was chosen

- It survives 16px without a second drawing, which was the stated requirement. B does too; C does
  not.
- It says what the product is. A ledger is not a metaphor for lending infrastructure, it is the
  artefact — and it avoids all three named clichés: no growth arrow, no handshake, no rupee sign.
- Four flat shapes and two flat colours mean the monochrome variants are the same drawing with one
  fill changed. A gradient mark would have failed the letterhead, the generated PDF header and the
  email signature, which is where this ends up.
- The implied L ties the mark to the name without being a letterform logo.

Refined from the first pass: the second entry line was mid-grey, which vanished at 16px against
white. It is now the same slate as the structure, so the only tonal contrast is the one accent bar.

## Files

| File | Use |
|---|---|
| `logo/mark.svg` | The mark alone, two colour |
| `logo/mark-mono-dark.svg` | One colour, for light backgrounds |
| `logo/mark-mono-light.svg` | One colour, reversed |
| `logo/wordmark.svg` | "Lenviq", outlines |
| `logo/lockup-horizontal.svg` | Mark + wordmark, the default |
| `logo/lockup-stacked.svg` | Where the horizontal is too wide |
| `logo/lockup-horizontal-mono-*.svg` | One-colour lockups |
| `public/favicon.ico` | 16/32/48, each rendered at its own size |
| `public/favicon.svg` | Modern browsers |
| `public/apple-touch-icon.png` | 180px, opaque, slate ground |
| `public/icon-192.png`, `icon-512.png` | Manifest |
| `public/og.png` | 1200×630 |
| `public/site.webmanifest` | Manifest |

The wordmark is set in Bricolage Grotesque ExtraBold at −0.03em and converted to outlines from the
**same woff2 file the site loads**, so it cannot drift from the headline typeface.

## Fonts and their licences

Both are **SIL Open Font License 1.1**, which permits self-hosting, bundling with a commercial
product, and redistribution as part of that product. The licence requires the copyright notice and
licence text to travel with the font files, which is why `brand/fonts/` carries both.

| Family | Copyright | Licence |
|---|---|---|
| Bricolage Grotesque | 2022 The Bricolage Grotesque Project Authors | SIL OFL 1.1 |
| Plus Jakarta Sans | 2020 The Plus Jakarta Sans Project Authors | SIL OFL 1.1 |

Two things the OFL does prohibit, neither of which applies here: selling the fonts on their own,
and using the Reserved Font Name on a modified version. The files are used unmodified apart from
subsetting, which the licence permits.
